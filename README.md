# Sorting Algorithms & Big O

## Description

Ce projet a pour objectif de découvrir et d'implémenter différents algorithmes de tri en langage C tout en étudiant leur complexité algorithmique grâce à la notation **Big O**.

Chaque algorithme sera développé à partir de zéro afin de comprendre son fonctionnement, ses avantages, ses limites et les situations dans lesquelles il est le plus adapté.

Les implémentations respecteront les normes de codage **Betty** ainsi que les contraintes du projet Holberton.

---

## Objectifs pédagogiques

À la fin de ce projet, nous serons capables de :

* Comprendre le rôle des algorithmes de tri.
* Expliquer le fonctionnement de plusieurs méthodes de tri.
* Analyser la complexité temporelle d'un algorithme grâce à la notation Big O.
* Comparer les performances de différents algorithmes.
* Manipuler des tableaux et des listes doublement chaînées.
* Écrire un code propre, modulaire et documenté.

---

## Algorithmes étudiés

Au cours du projet, les algorithmes suivants seront implémentés :

* Bubble Sort
* Insertion Sort
* Selection Sort
* Quick Sort
* Shell Sort
* Cocktail Shaker Sort
* Counting Sort
* Merge Sort
* Heap Sort
* Radix Sort
* Bitonic Sort

## Complexité algorithmique

Chaque algorithme est accompagné d'un fichier contenant ses complexités en notation Big O :

* Meilleur cas
* Cas moyen
* Pire cas

L'objectif est de comprendre non seulement comment fonctionne un algorithme, mais également son coût lorsque la taille des données augmente.
